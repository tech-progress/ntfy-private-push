# Support boundary

Template release **v1.0.1** is a self-contained single-replica, low-volume evaluation recipe for [ntfy](https://ntfy.sh/). This release must be qualified independently. Historical `v1.0.0` source proof does not establish this release's qualification, and a source release does not prove marketplace publication. Follow the qualification and publication readback gates in [PUBLISHING.md](PUBLISHING.md). It does not provide managed-service support, multi-node availability, performance sizing or an exactly-once guarantee.

401 means missing/incorrect credentials; 403 means the authenticated user lacks that topic ACL. Topic names are not security credentials. If boot fails with missing auth-file, verify the initializer can write its exclusive volume. If replay is absent, inspect retention and cache-file persistence, not just HTTP readiness. Changing the bootstrap password rotates it on startup, but existing tokens require separate revocation with ntfy token remove. Browser permission, stable VAPID keys and HTTPS are separate from HTTP notification health. Never attach auth.db or print access tokens in logs.

Cache retention defaults to 24h with a 1m pruning cadence. The volume has no hard cache byte cap; monitor usage and message rates. Previously cached message expiry does not change just because the default duration changes. Browser Web Push/VAPID delivery and subscription restore, external mobile relays, expanded multi-user administration and hostile-tenant isolation are outside the default qualified HTTP workflow.

Provide template VERSION, actual selected source revision, exact upstream pins, failing command/HTTP status and redacted logs. Do not provide token output, auth databases, passwords, customer payloads, VAPID private keys or raw SQLite backups. Run `node scripts/verify-docs.mjs` and `node --test tests/docs.test.mjs` for docs issues; reproduce runtime issues with `scripts/verify.sh` and an isolated `scripts/local-smoke.sh`. Those runtime scripts need Docker and remove only their own disposable resources. Historical successful tests do not replace this release's verification. Escalate product bugs [upstream](https://github.com/binwiederhier/ntfy/issues) after separating wrapper configuration from upstream behavior. See [UPGRADE.md](UPGRADE.md) for coordinated backups and rollback.
